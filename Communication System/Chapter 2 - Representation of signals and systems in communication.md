# 1 Review of signals and system
- information carried by a signal will be a function of an independent variable.
- the dependent variable can be time, spatial coordinates, intensity of colors, pressure, temperature, etc.
- value of a signal at any specified value of the independent variable is = amplitude
- the plot of time as a function of independent variable = waveform.
- signal is defined as
	- any physical quantity that varies with one or more independent variables.
	- that conveys or carries some information
## 1.1 Types of Signals
### 1.1.1 Depending on the number of sources for the signal
#### 1.1.1.1 One Channel Signal
- signal that are generated by a single source or sensor are called one-channel signal
- record of room temperature vs time, audio output of mono speaker.
#### 1.1.1.2 Multi channel signals
- signal that are generated by multiple sources or sensors are called multichannel signals
- e.g.,
	- the audio output of two stereo speakers is an example of two-channel signal.
	- the record of ECG at 8 different places in human body -> eight-channel signal.
### 1.1.2 Depending on the number of dependent variables
#### 1.1.2.1 One Dimensional Signals
- signal which is a function of single independent variable
- e.g.,
	- music, speech, heartbeat
#### 1.1.2.2 Multi Dimensional Signals
- signal which is function of 2 or more independent variable
- e.g.,
	- photograph is 2d signal. intensity and brightness of each pixel is dependent on x and y coordinates.
	- if video, then 3d signal, x, y, t.
### 1.1.3 Depending on whether dependent variable is continuous or discrete
#### 1.1.3.1 Analog/Continuous
- when a signal is defined continuously for any value of independent variable
- most of natural signals
#### 1.1.3.2 Discrete
- when a signal is defined for discrete intervals of independent variable
- when dependent variable of a discrete signal is time, its called discrete time signal.
## 1.2 Continuous Time Signals
### 1.2.1 Standard Continuous Time Signals
#### 1.2.1.1 Impulse Signal
- The impulse signal is a signal with infinite magnitude and zero duration, but with an area of A.
- Mathematically, $$\large
\begin{aligned}
	
  \delta(t) &= 0;\ t = 0 \\
   &= 0;\ t \ne 0\\
   \text{and}\\
   \int_{-\infty}^{\infty} \delta(t)\ dt &= A
\end{aligned}
$$
- if unit impulse, then the integration = 1
##### 1.2.1.1.1 Properties of unit impulse
- $$\large \int_{-\infty}^{\infty} \delta(t)\ dt = 1$$
- $$\large \int_{-\infty}^{\infty} x(t)\ \delta(t)\ dt = x(0)$$
- $$\large \int_{-\infty}^{\infty} x(t)\ \delta(t-t_0)\ dt = x(t_0)$$
- $$\large \int_{-\infty}^{\infty} x(\lambda)\ \delta(t-\lambda)\ d\lambda = x(t)$$
- $$\large \int_{-\infty}^{\infty} \delta(at)\ dt = \dfrac{1}{|a|}\delta(t)$$
#### 1.2.1.2 Step Signal
- Mathematically, $$
\begin{aligned}
  \text{x}(t) &= A;\ t  \ge\ 0 \\
   &= 0;\ t \ne 0
\end{aligned}
$$
- if unit step, x(t) = u(t) = 1; t $\geq$ 0
#### 1.2.1.3 Ramp Signal
- Mathematically, $$
\begin{aligned}
  \text{x}(t) &= At;\ t \ge\ 0 \\
   &= 0;\ t \ne 0
\end{aligned}
$$
- if unit step, x(t) = t; t $\geq$ 0
#### 1.2.1.4 Parabolic Signal
- Mathematically, $$
\begin{aligned}
  \text{x}(t) &= \dfrac{At^2}{2};\ t \ge 0 \\
   &= 0;\ t \ne 0
\end{aligned}
$$
- if unit step, x(t) = $\dfrac{t^2}{2}$; t $\geq$ 0
#### 1.2.1.5 Unit Pulse Signal
- Mathematically, $$\large \text{x}(t) = \Pi(t)\ =\ u\left(t+\dfrac12\right)\ -\ u\left(t-\dfrac12\right)$$
#### 1.2.1.6 Sinusoidal Signal
1. Cosinusoidal Signal
	- x(t) = A $\cos(\Omega_{0} t + \phi)$
		- where, $\Omega_0$ = 2$\pi$F$_0$ = $\dfrac{2\pi}{T}$ = Angular frequency in rad/s
		- F$_0$ = frequency in cycles/sec or Hz
		- T = time period in sec
	- when $\phi$ = 0, x(t) = A $\cos(\Omega_{0} t)$
	- when $\phi$ = +ve, x(t) = A $\cos(\Omega_{0} t + \phi)$
	- when $\phi$ = -ve, x(t) = A $\cos(\Omega_{0} t - \phi)$
2. Sinusoidal Signal
	- x(t) = A $\sin(\Omega_{0} t + \phi)$
		- where, $\Omega_0$ = 2$\pi$F$_0$ = $\dfrac{2\pi}{T}$ = Angular frequency in rad/s
		- F$_0$ = frequency in cycles/sec or Hz
		- T = time period in sec
	- when $\phi$ = 0, x(t) = A $\sin(\Omega_{0} t)$
	- when $\phi$ = +ve, x(t) = A $\sin(\Omega_{0} t + \phi)$
	- when $\phi$ = -ve, x(t) = A $\sin(\Omega_{0} t - \phi)$
#### 1.2.1.7 Exponential Signal
1. Real exponential signal
	- $$\large x(t) = A e^{bt}$$
	- where, A and b are real
	- here, b -> +v, then exponentially rising signal
2. Complex exponential signal
	- $${\large x(t) = A\ e^{j\Omega_0t}}$$
	- can be resolved further: $$\large x(t) = A(\cos(\Omega_{0}t) +j\ \sin(\Omega_{0}t))$$
	- so, A$\cos(\Omega_0t)$ = real part of x(t)
	- and A$\sin(\Omega_0t)$ = imaginary part of x(t)
#### 1.2.1.8 Exponentially varying sinusoidal signal
- x(t) = $$\large A\ e^{bt} \sin(\Omega_{0}t)$$
- where $\Omega_0$ = 2$\pi$F$_0$ = $\dfrac{2\pi}{T}$
- A and b are real constants.
- when b > 0 -> exponentially rising sinusoidal signal;
- when b < 0 -> exponentially decaying sinusoidal signal
#### 1.2.1.9 Triangular Pulse Signal
- x(t) = $$\large \begin{align} \Delta_{a}(t) &= 1 - \dfrac{|t|}{a}\ ;\ |t| \le a\\ &= 0\ ;\ |t| > a \end{align}$$
#### 1.2.1.10 Signum signal
x(t) = $$\large \begin{align}sgn(t) &= 1\ ;\ t >0\\ &= 0\ ;\ t = 0\\ &= -1\ ;\ t < 0 \end{align}$$
#### 1.2.1.11 Gaussian Signal
x(t) = $$\large g_{a(t)} = e^{-a^{2}t^{2}}\ ;\ -\infty < t<\infty  $$
#### 1.2.1.12 Sinc Signal
x(t) = sinc(t) = $$\large \dfrac{\sin(t)}{t};\ -\infty <t < \infty$$
### 1.2.2 Classification of Continuous Time Signals
#### 1.2.2.1 Deterministic & Non deterministic signals
- the signal that can be completely specified by a mathematical equation is called a deterministic signal
- the step, ramp, exponential and sinusoidal signals are examples of deterministic signals
- signal whose characteristics are random nature is called  non-deterministic signal.
- the noise signals from various sources like electronic amplifiers, oscillators, radio receivers, etc.
#### 1.2.2.2 Periodic & NonPeriodic signals
- have a definite pattern that repeats again and again over a certain period of time
- x(t) = x(t + T) is periodic, and T is its period
- if doesn't satisfy this condition, its called aperiodic or non periodic signal
##### 1.2.2.2.1 Periodicity
- x = 5 cos(4$\pi$t) + 3 sin(8$\pi$t)
- let x1(t) = 5 cos(4$\pi$t)
	- so, F$_{1}$ = $\dfrac{4\pi}{2\pi}$ = 2
	- then, T1 = 1/2
- let x2(t) = 3 sin(8$\pi$t)
	- so, F$_{2}$ = $\dfrac{8\pi}{2\pi}$ = 4
	- then, T2= 1/4
- LCM of T1 and T2 = 1/2.
- so time period = 1/2
#### 1.2.2.3 Symmetric and Antisymmetric signals
- when signal exhibits symmetry or antisymmetry with respect to t = 00
- when symmetry wrt t = 0, then even
	- x(-t) = x(t)
	- e.g., cos(t), x$^2$
- when antisymmetry wrt t = 0, then odd
	- x(-t) = -x(t)
	- e.g., sin(t), x
- any function can be expressed as a sum of even and odd signal$$\large x(t) = x_{e}(t)+ x_{o}(t)$$
	- $$\large x_e(t) = \dfrac12[x(t) + x(-t)]$$
	- $$\large x_o(t) = \dfrac12[x(t) - x(-t)]$$
- Properties
	- signal is even, then odd part -> 0
	- signal is odd, then even part -> 0
	- odd $\times$ odd = even
	- even $\times$ even = even
	- even $\times$ odd = odd
#### 1.2.2.4 Energy and Power signals
- The signals which have finite energy are called energy signal
- the non periodic signals like exponential signals will have constant energy and so non periodic signals are energy signals.
- the signals which have finite average power are also called power signals.
- the periodic signals like sinusoidal and complex exponential signals will have constant power and so periodic signals are power signals.
- the energy E of a continuous time signal x(t) is defined as $$\large E = \lim_{T\ \rightarrow\ \infty} \int_{-T}^{T} |x(t)|^2\ dt\ \text{in joules}$$
- For energy signals, the energy will be finite (or constant) and average power will be zero
- the average power of a continuous time signal x(t) is defined as $$\large P = \lim_{T\ \rightarrow\ \infty} \dfrac{1}{2T}\int_{-T}^{T} |x(t)|^2\ dt\ \text{in watts}$$
- for periodic signals, the average power one period will be same as average over an infinite interval $$\large P = \dfrac{1}{T} \int_0^T |x(t)|^2 dt$$
- for power signals the average power is finite (or constant) and energy will be infinite.

#### 1.2.2.5 Causal, Noncausal and anti causal signals
- a signal is said to be causal, if it is defined for t >= 0
- therefore if x(t) is causal, then x(t) = 0 , for t < 0
- a signal is said to be non-causal, if it is defined for either t =< 0, or both t =< 0 and t > 0
- x(t) is non causal, then x(t) != 0, for t < 0
- when a non causal signal is defined only for t =< 0, it is called anticausal signal.
### 1.2.3 Operation on Signals
#### 1.2.3.1 Scaling
##### 1.2.3.1.1 Amplitude Scaling
- performed by multiplying the amplitude of the signal by a constant.
- for x(t) as a signal, amplified signal is A x(t), where A is constant
	- A > 1 -> magnified
	- A < 1 -> attenuated
##### 1.2.3.1.2 Time Scaling
- performed by multiplying the time variable by a constant
- for x(t) as a signal, time scaled signal is x(At), where A is constant.
	- A > 1 -> time compressed
	- A < 1 -> time expanded
#### 1.2.3.2 Folding (Reflection/Transpose)
- performed by changing the sign of time
- for x(t) as a signal, folded signal is x(-t)
- produces mirror image behind Y-axis
#### 1.2.3.3 Time Shifting
- performed by replacing the independent variable t by t - m
- for x(t) as a signal, time shifted signal is x(t - m)
- m > 0 -> introduces a delay
- m < 0 -> introduces an advancement
#### 1.2.3.4 Addition
- performed by adding the value of two signals corresponding to same instant of time
- for x1(t) and x2(t) as signals, added signal is y(t) = x1(t) + x2(t)
#### 1.2.3.5 Multiplication
- performed by multiplying the value of two signal corresponding to the same instant of time
- for x1(t) and x2(t) as signals, multiplied signal is y(t) = x1(t) * x2(t)

## 1.3 Types of Systems
Based on their characteristics
### 1.3.1 Static and dynamic systems
- a continuous time system is called static or memoryless
	- if its output at any instant of time t depends at most on the input signal at the same time but not one the past or future input.
- in any other case, the system said to be dynamic or to have memory
- example:
	- static: y(t) = t x(t) + 6 x$^3$(t)
	- dynamic: y(t) = x(t) + 3 x(t - 2)
### 1.3.2 Time invariant and variant
- a system is said to be time invariant if its input-output characteristics does not change with time.
- a relaxed system H is time invariant or shift invariant if and only if
	- x(t) -- H -> y(t) implies that, x(t-m) -- H -> y(t-m)
	- for every input signal x(t) and every time shift m.
- i.e. in time varient systems, if y(t) = H{x(t)} then y(t-m) = H{x(t)})
- a system H is time invariant if the response to a shifted (or delayed) version of the input is identical to a shifted (or delayed) version of the response based on the unshifted (or delayed) input
- the diagrammatic explanation of the above definition of time invariance is shown below:
	- x(t) -- Delay -> x(t - m) -- H -> y1(t)
	- x(t) -- H -> y(t) -- Delay -> y2(t)
	- if y1(t) = y2(t) then the system is time invariant
#### 1.3.2.1 Test of variance
- y(t) = 3x(t^2)
- response for delayed input:
	- x(t) -- Delay -> x(t - m) -- H -> y1(t)
	- so, y1(t) = 2t x(t-m)
- delayed response
	- x(t) -- H -> y(t) -- Delay -> y2(t)
	- y(t) = 2t(xt)
	- y2(t) = 2(t-m) x(t-m)
- y1 != y2, so time variant
### 1.3.3 Linear and Non-linear systems
- a linear system is the one that satisfies the superposition principle
- the principle requires that the response of a system to a weighted sum of the signals is equal to the corresponding weighted sum of the response to each of the individual input signals.
- A relaxed system H is linear if
	- H{a1 x1(t) + a2 x2(t)} = a1 H{x1(t)} + a2 H{x2(t)}
	- for any arbitrary input signal x1(t) and x2(t) and for any arbitrary constants a1 and a2.
- if doesn't satisfy the superposition principle, then system is non linear.
#### 1.3.3.1 Test of linearity
- take y(t) = A x(t) + B
	- y(t) = H{x(t)} = A x(t) + B
	- y1(t) = A x1(t) + B
	- y2(t) = A x2(t) + B
- y3(t) = H{ a1 x1(t) + a2 x2(t) }
	- y3(t) = A ( a1 x1(t) + a2 x2(t) ) + B
	- = a1 A x1(t) + a2 A x2(t) + B
- if linear, y3(t) = a1 y1(t) + a2 y2(t)
	- (a1 A x1(t) + a1 B) + (a2 A x2(t) + a2 B)
- since H{ a1 x1(t) + a2 x2(t) } != a1 y1(t) + a2 y2(t), not linear
### 1.3.4 Causal and non causal systems
- system is casual if the output of the system at any time t depends only on the present input, past inputs and past outputs does not depend on the future inputs and outputs
- if the system output at any time t depends on future inputs or outputs then the system is called a non casual system.
- the causality refers to a system that is realizable in real time.
- LTI is casual if and only if the impulse response is zero for t < 0, (i.e., h(t) = 0 for t < 0).
#### 1.3.4.1 Test of causality
- take y(t) = x(t) - x(t-1)
	- when t = 0
		- y(0) = x(0) - x(-1)
		- response at t= 0, depends on present input and past input
	- when t = 1,
		- y(t) = x(1) - x(0)
		- same response at t=1
	- so, for any value of t, system output depends on the present and past inputs
	- so system is casual
- take y(t) = x(t) + $\large \int_0^{3t}\ x(\lambda)\ d\lambda$,
	- solving one step further:
	- y(t) = x(t) + \[X($\lambda$)]$_0^{3t}$
	- y(t) = x(t) + X(3t) - X(0)
	- when t = 0,
		- y(0) = x(0) + X(0) - X(0) -> present inputs
	- when t = 1,
		- y(1) = x(1) + X(3) - X(0) -> present, past and future
	- since present, past and future is needed, non causal.
### 1.3.5 Stable and Unstable systems
- relaxed system is said to BIBO stable (Bounded Input-Bounded Output stable) if and only if every bounded input produces a bounded output.
- let x(t) be the input of continuous time system and y(t) be the response or output for x(t)
- then bounded input refers to finite value of input signal x(t) for any value of t.
- hence if input x(t) is bounded then there exists a constant M$_x$ such that |x(t)| =< M$_x$ and M$_x$ < $\infty$ for all t
- example:
	- bounded: step signal, decaying exponential signal
	- unbounded: ramp signal and increasing exponential signal
- the term bounded output refers to infinte and predictable output for any value of t.
- hence if output y(t) is bounded then there exists a constant M$_y$ such that |y(t)| =< M$_y$ and M$_y$ for all t
- in general the test for stability of the system is performed by applying specific input.
- on applying a bounded input to a system if the output is bounded then the system is said to be BIBO stable.
#### 1.3.5.1 Condition for stability
- for stability of an LTI system $$\int_{-\infty}^\infty |h(t)| dt\ <\ \infty$$
#### 1.3.5.2 Test of stability
- y(t) = e$^{4t} u(t)$
- for stability
	- $$\large \int_{-\infty}^{\infty} |h(t)|\ dt\ =\ \int_{-\infty}^{\infty} |e^{4t}\ u(t)|\ dt\ =\ \int_{-\infty}^{\infty} e^{4t} u(t) dt\ =\ \int_0^\infty e^{4t}dt\ =\ \infty - \dfrac14\ =\ \infty$$
- so unstable
### 1.3.6 Feedback and non feedback systems
- system in which output y(t) at any time t depends on past output, past input and present input is called a feedback system.
- the equation governing feedback systems will be in form of:
$$\large a_0 \dfrac{d^n}{dt^n}y(t)\ +\ a_1 \dfrac{d^{n-1}}{dt^{n-1}}y(t)\ +\ a_2 \dfrac{d^{n-2}}{dt^{n-2}}y(t)\ +\ ... +\ a_n y(t)\ =\ b_0 \dfrac{d^m}{dt^m}x(t)\ +\ b_1 \dfrac{d^{,-1}}{dt^{m-1}}x(t)\ +\ b_2 \dfrac{d^{m-2}}{dt^{m-2}}x(t)\ +\ ... +\ b_m x(t) $$
### 1.3.7 Convolution of Continuous Time Signals
- convolution of x1 (t) and x2(t) is defined as: $$\large x_3(t)\ =\ \int_{-\infty}^\infty\ x_1(\lambda)\ x_2(t-\lambda)\ d\lambda$$
- convolution can be expressed as: x3(t) = x1(t) * x2(t)
#### 1.3.7.1 Response of LTI continuous time system using convolution
$$y(t) = x(t) * h(t)\ =\ \int_{-\infty}^\infty\ x(\lambda)\ h(t-\lambda)\ d\lambda$$
Proof:
- let y(t) = H{x(t)}
- signal can be expressed as integral of impulses:
	- $$x(t) = \int_{-\infty}^\infty\ x(\lambda)\ \delta(t-\lambda)\ d\lambda$$
	- where $\delta(t-\lambda)$ is delayed unit impulse signal
- so we have:
	- $$\large
	\begin{align} y(t) &= H\left[\int_{-\infty}^\infty x(\lambda)\ \delta(t-\lambda)\ d\lambda \right]\\
	&= \int_{-\infty}^\infty H[x(\lambda)\ \delta(t-\lambda)]\ d\lambda\\
	& = \int_{-\infty}^\infty x(\lambda)\ H[\delta(t-\lambda)]\ d\lambda
	\end{align}$$
	- let the response of the LTI system to the unit impulse input $\delta(t)$ be donoted by h(t).
		- i.e. h(t) = H\[$\delta$(t)]
	- since its time-invariant, we have:
		- h\[$\delta$(t-$\lambda$)] = h(t-$\lambda$)
	- so finally we have:
		- $$\large y(t) = \int_{-\infty}^\infty\ x(\lambda) h(t-\lambda) d\lambda$$
- Hence we proved:
	- y(t) of LTI continuous time system for arbitrary input x(t)
	- is given by
	- convolution of input x(t) with impulse response h(t) of the system.
